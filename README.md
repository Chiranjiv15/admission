# RMK College of Engineering and Technology — Admission Website

## Files
- `index.html` — home page, college information, CSE/AI/ECE cards, sample admission status.
- `admission.html` — separate admission application page.
- `style.css` — shared responsive styling for both pages.
- `assets/` — reserved for optional local images.

## Run in VS Code
1. Extract the ZIP folder.
2. Open the `RMK_CET_Admission_Website` folder in Visual Studio Code.
3. Make sure `index.html`, `admission.html`, and `style.css` are together in the root folder.
4. Open `index.html` in a browser, or install the Live Server extension and choose **Open with Live Server**.
5. Click **Apply Now** to open `admission.html`.

## Important limitations
This is a frontend-only prototype built with HTML and CSS. The form uses browser-native required-field validation, but it does not store applications, send form data to a server, upload documents, or provide a live admission status. Do not enter sensitive personal information into a demonstration page.
The Google Font is optional; if the internet is unavailable, the page falls back to Arial.
